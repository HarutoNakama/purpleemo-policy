よくある質問

  • アプリが起動しない／落ちる：端末の再起動、アプリのアップデートをお試しください。
  • 動作が重い：他アプリを終了し、端末の空き容量をご確認ください。
  • 不具合報告：下記「送っていただきたい情報」を可能な範囲でお知らせください。

送っていただきたい情報

  • OS：iOS / Android、OSバージョン（例：iOS 17.x / Android 14）
  • 端末名（例：iPhone 14 / Pixel 7）
  • アプリのバージョン（例：1.0.0）
  • 発生日時（例：2026-01-17 20:15）
  • 再現手順（何をすると起きるか）
  • 可能ならスクリーンショット／画面録画

Privacy Policy: /privacy/

FAQ

  • The app won’t launch / crashes: Please restart your device and update the app to the latest version.
  • Performance is slow: Close other apps and check available storage on your device.
  • Bug report: Please include the information listed below if possible.

Information to Include

  • OS: iOS / Android and OS version (e.g., iOS 17.x / Android 14)
  • Device model (e.g., iPhone 14 / Pixel 7)
  • App version (e.g., 1.0.0)
  • Date/time of the issue (e.g., 2026-01-17 20:15 JST)
  • Steps to reproduce (what you did before it happened)
  • Screenshots / screen recording if available
